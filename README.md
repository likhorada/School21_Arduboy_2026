# 🗑️ Garbage Collector

> *🇬🇧 [English version](README.en.md)*

**Мусорщик очищает память от мусора, чтобы освободить место для запуска основной программы.**

---

## 🎮 Core Gameplay

Цикл строится на трёх столпах: **действие → награда → развитие**.

1. Мусорщик уничтожает врагов, двигаясь по арене и избегая их атак.
2. С врагов выпадают очки.
3. После прохождения арены открывается магазин улучшений — очки тратятся на прокачку.
4. (Не)улучшенный мусорщик выходит на следующую арену — и так до финальной.

## ⚙️ Ограничения проекта

Платформа **Arduboy** — сама по себе вызов:

- жёсткие технические ограничения по памяти для программиста;
- ограниченный визуальный стиль (монохромный экран, низкое разрешение) для художника.
